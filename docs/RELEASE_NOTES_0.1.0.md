# Media Multiviewer 0.1.0

The first public release provides a local workspace for up to four
user-approved browser tabs or windows.

## Highlights

- 2-up, 3-up, 2×2, Hero, focus, and native fullscreen views;
- one active audio source with direct keyboard selection;
- animated drag-and-drop ordering with local preference persistence;
- automatic browser-label naming and optional local-frame OCR suggestions;
- synthetic demo mode for safe interface testing;
- no accounts, media proxy, recorder, analytics, or database.

## Boundaries

The browser requires explicit approval for every captured surface. Availability
of tab audio depends on the browser and operating system. Protected media can
appear black or refuse capture, and this project does not bypass DRM, paywalls,
authentication, or other access controls.

Only capture and display content you are authorized to use.
