# Security policy

## Supported versions

Security fixes are applied to the latest revision of the default branch.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Older revisions | No |

## Reporting a vulnerability

Do not disclose vulnerabilities in a public issue. Use GitHub private
vulnerability reporting and include reproduction steps, impact, affected
browser versions, and any suggested mitigation.

Never attach captured media, cookies, session tokens, private URLs, browser
profiles, or screen-sharing diagnostics to a public report.

Media Multiviewer does not require accounts or credentials and does not send
captured streams to an application server.

## Response expectations

Reports are reviewed on a best-effort basis. Please allow time to reproduce the
issue before publishing details, and coordinate disclosure through the private
report.
