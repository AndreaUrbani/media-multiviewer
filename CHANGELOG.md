# Changelog

## 0.1.0 — 2026-08-17

- Four-source local browser multiview.
- Secure tab/window selection through `getDisplayMedia`.
- Single-source audio control, focus mode, and native fullscreen.
- Persistent local source labels and a built-in synthetic demo.
- Screen-first compact layout with direct audio, single-view, grid, and
  fullscreen keyboard controls.
- Demo V2 with a contained 16:9 calibration frame and visible corner markers.
- Minimal monochrome interface and neutral Media Multiviewer branding.
- Persistent two-source, three-source, 2×2, and selected-source hero layouts.
- Drag-and-drop source ordering that keeps active captures connected.
- Animated live tile reordering and local OCR-assisted source naming.
- GitHub CI, release checks, community files, and publication guides.
